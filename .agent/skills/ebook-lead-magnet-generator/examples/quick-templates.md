## Quick Format Selection Guide

| Need                 | Best Format           | Pages |
| -------------------- | --------------------- | ----- |
| Step-by-step process | Checklist             | 1-3   |
| Reference/lookup     | Cheat sheet           | 1-2   |
| Fill-in planning     | Template/worksheet    | 2-5   |
| Inspiration/examples | Swipe file            | 5-15  |
| Tool recommendations | Toolkit/resource list | 3-10  |
| How-to instructions  | Guide                 | 10-20 |
| Deep-dive education  | Ebook                 | 20-50 |
