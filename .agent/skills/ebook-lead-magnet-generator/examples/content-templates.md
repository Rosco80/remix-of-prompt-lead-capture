# Content Templates

## Chapter Template

```markdown
## Chapter [#]: [Chapter Title]

### Opening Hook

[1-2 paragraphs introducing the chapter topic and why it matters]

### Key Concept 1

[Heading + 2-3 paragraphs explaining the first main idea]

**Example/Case Study:**
[Real-world illustration of the concept]

### Key Concept 2

[Heading + 2-3 paragraphs for second main idea]

> **Pro Tip:** [Callout box with actionable advice]

### Key Concept 3

[Heading + 2-3 paragraphs for third main idea]

### Chapter Summary

**Key Takeaways:**

- [Takeaway 1]
- [Takeaway 2]
- [Takeaway 3]

**Action Step:**
[One specific thing reader should do before moving on]

---
```

## Callout Box Types

```markdown
> **💡 Pro Tip:** [Actionable shortcut or insider advice]

> **⚠️ Warning:** [Common mistake to avoid]

> **📋 Quick Checklist:**
>
> - [ ] Item 1
> - [ ] Item 2
> - [ ] Item 3

> **🔑 Key Definition:** [Term]: [Definition]

> **📊 Stat:** [Compelling statistic with source]

> **🎯 Action Step:** [Specific task for reader]
```

## Page Element Types

| Element         | Purpose              | Usage              |
| --------------- | -------------------- | ------------------ |
| Headers (H1-H3) | Structure, scanning  | Every section      |
| Body paragraphs | Core content         | 3-5 sentences max  |
| Bullet lists    | Multiple points      | Limit to 5-7 items |
| Numbered lists  | Sequential steps     | For processes      |
| Callout boxes   | Tips, warnings       | 1-2 per chapter    |
| Quotes          | Authority, emphasis  | Sparingly          |
| Images/diagrams | Visual explanation   | Every 2-3 pages    |
| Tables          | Comparisons, data    | When appropriate   |
| Checklists      | Actionable summaries | End of chapters    |

## Cover Page Elements

```markdown
## Cover Page

**Title:** [Main title - max 6 words]
**Subtitle:** [Value prop or description - max 12 words]
**Visual:** [Hero image or illustration concept]
**Branding:** Company logo, URL
**Year:** [Publication year]
```

## Title Formulas

| Formula                          | Example                                   |
| -------------------------------- | ----------------------------------------- |
| The [Adjective] Guide to [Topic] | "The Complete Guide to Email Marketing"   |
| [Number] [Things] to [Outcome]   | "10 Steps to Double Your Conversion Rate" |
| How to [Achieve Goal]            | "How to Build a 6-Figure Online Business" |
| [Topic] [Timeframe]              | "Content Marketing in 2026"               |
| The [Audience]'s [Resource]      | "The Marketer's Playbook"                 |
| [Topic]: [Benefit]               | "Lead Generation: From Zero to Pipeline"  |

## Introduction Template

```markdown
## Introduction

### Who This Guide Is For

[1 paragraph describing the ideal reader and their situation]

### What You'll Learn

By the end of this [ebook/guide], you'll be able to:

- [Outcome 1]
- [Outcome 2]
- [Outcome 3]

### How to Use This Guide

[Instructions for getting the most value - read straight through,
use as reference, complete exercises, etc.]

### About [Company/Author]

[2-3 sentences establishing credibility and why you're qualified
to write this]

Let's get started.
```
